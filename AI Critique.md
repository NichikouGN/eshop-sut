For this specific task the AI is quite good at generating the initial list of checklist to be used. It can read the code itself to have some rough ideas of what area can be tested on and which need more attention. However the thing is it still makes alot of assumptions on what a normal flow should be. For example some checklist assume the OTP flow works as normal, you supply an email, get it from the email and type in the OTP. What it failed to realize is the fact that the OTP is shown directly in the client which is a major vulnerability issue. Another potential issue is the checklist is universal so it may not account for some specific quirks with some of the web app like Safari being wildly different from that of Chrome or Firefox. All in all it is still good t have AI help in doing this exercise as it speeds up alot of the thing that would have been done manually like writing down each test cases, counting for a finaly summary, giving additional advices,...
